# PayPal Checkout Performance Analysis

## Project Overview
This business analysis portfolio project explores checkout funnel performance, payment authorization, and checkout completion across device types and checkout experiences.

The project uses SQL for data analysis and Power BI for visualization to demonstrate business analysis, KPI development, and data storytelling skills.

## Business Questions
- Where do users drop off in the checkout funnel?
- How does checkout completion vary by device type?
- How does the redesigned checkout experience compare with the standard experience?
- How do payment authorization rates vary by payment method?
- What opportunities could improve checkout performance?

## Tools & Technologies
- SQL and SQLite
- Python for data preparation
- Microsoft Power BI
- Excel/CSV

## Dashboard Metrics
- Total checkout sessions
- Completed purchases
- Checkout completion rate
- Checkout funnel
- Payment authorization rate by payment method
- Checkout completion by version
- Checkout completion by device

## Key Findings
The illustrative analysis of the synthetic dataset shows differences in checkout completion across checkout versions and device types. These results are used to practice identifying potential improvement areas and communicating findings through a dashboard.

## Data Disclaimer
**This project uses synthetic data created for portfolio and educational purposes. It does not contain PayPal's actual transaction data, and the findings must not be interpreted as PayPal's real-world performance or as causal evidence.** Publicly available company information may inform the business context, but the dashboard metrics are derived from the synthetic dataset.
